# Design context

## Audience

Barghsa electricity customers and the staff managing their orders, payments, profiles and support. Persian is the primary interface language; English remains supported.

## Jobs

Find current status, review exact financial amounts, complete existing service requests, manage profiles and resolve operational work. Show a clear recovery path when data is unavailable.

## Agreed direction

The user approved a calm, precise Persian-first workspace with warm neutral backgrounds, deep teal actions and restrained amber accents. They explicitly requested Vazirmatn. Use its local Arabic and Latin variable font assets throughout. Administrator branding still overrides the configured action colors.

## Scope

Refresh implemented features. Do not add unfinished features to live pages. Reusable future components belong in the shared UI package and development catalogue.

Only authentication, main dashboard and admin/customer shell layouts may change. Preserve other feature-page structure. Prefer existing Base UI/shadcn primitives and installed dependencies.

Detailed guidance: `docs/design/design-system.md`.
