# Customer history search and sorting

Canonical work: `07-ui-ux-design.md#T-07.18.01.04` (`ListSortDropdown`), the `TextFilter` portion of `07-ui-ux-design.md#T-07.18.02.03`, and URL persistence from `07-ui-ux-design.md#T-07.18.02.04` on saving, solar, and consultation customer histories. Number, select and multi-select filters, the wider list framework, and adoption across other lists remain open.

The shared text filter waits 300ms after typing, cancels pending work on navigation or unmount, and restores its value from the URL. The shared sort dropdown uses the same allowlist as the three APIs: submission date, newest or oldest first. Search and sort compose with existing date/status selections, survive reload and Back, and reset loaded pages and cursors. Consultation form selection remains intact when these controls change. Controls and reference labels use both dictionaries and support RTL and mobile layouts.

Saving searches visible plan/equipment titles in either language, bill identifiers and order references. Consultation searches service titles in either language and request references. Solar searches request references. References are now visible on all three histories. APIs trim search text, reject control characters and inputs over 120 characters, bind text as query parameters, and escape LIKE wildcard characters so `%`, `_` and backslashes are literal. Both cursor lookup and row selection apply the same profile, search, status and date constraints before the 100-row page limit. Both sort directions use submission timestamp plus UUID for deterministic pagination, including tied timestamps. The OpenAPI contract documents `q` and the sort allowlist.

Validation: three PostgreSQL HTTP integration suites (10 tests), 27 shared query/date/status parser tests, full web tests (1,159), UI tests (64), translation tests (53), 30 bilingual filter/sort flows across Chromium, Firefox, WebKit, Android and iPhone projects, five existing customer journey flows, root build/typecheck/lint/format, OpenAPI consistency, all 64 bundle budgets and generated backlog validation. Code review confirmed the same filter constraints in cursor and row queries, bound literal search text, allowlisted SQL ordering, and cancellation of stale page responses and pending text changes.

The preceding date-filter batch's remote CI completed successfully. The paused automation and historical loop-state files remain unchanged.
