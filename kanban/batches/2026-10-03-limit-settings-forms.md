# Contract and finance limit forms, October 3, 2026

## Scope and behavior

This batch adopts shared forms across contract electricity limits, online wallet top-up caps and dual-approval thresholds. It advances `07-ui-ux-design.md#T-07.10.01.02`, `07-ui-ux-design.md#T-07.10.01.04`, `07-ui-ux-design.md#T-07.10.01.05` and `07-ui-ux-design.md#T-07.10.01.06`; these global form tasks remain partial. Existing business rules behind `02-auth-users-admin.md#T-09.12.06`, `02-auth-users-admin.md#T-09.10.01` and `02-auth-users-admin.md#T-09.07.01` remain enforced.

Deferred Zod Mini validates raw drafts with linked bilingual errors, first-error focus and submission locks. Contract percentages, months and days obey their existing bounds. Financial amounts accept exact Persian/Arabic digits and correctly grouped thousands; signs, exponents, decimals, malformed grouping and unsafe integers are rejected without stripping characters. Formatted IRR/current-value and Toman previews remain. Zero blocks online top-ups; zero disables dual approval only for new operations.

Failed or malformed reads retain accepted edits and block writes. Unchanged reads preserve raw drafts; changed settings withdraw obsolete work. Contract confirmations retain their frozen values through an unchanged recovery read and pause while settings are unavailable. Wallet proposals capture the current optimistic version, including when another writer changes only that version. Threshold changes retain OTP verification. Receipts must match captured values and the wallet's next version; uncertain writes require cancellation and an accepted reload. Editing clears obsolete saved status. Review fixes a shared close callback so an old cancelled dialog cannot close a newer proposal.

Contract and wallet API errors expose only owned form fields after permission checks. Unknown/mixed errors remain general without reflecting private keys or values. Existing aliases, compatible wallet extras, concurrency checks, live authority, CSRF, step-up, transactions, audits and order/payment snapshots remain. Shared status/submit feedback is extracted from the electricity page without changing its behavior. No dependency, migration or endpoint is added.
