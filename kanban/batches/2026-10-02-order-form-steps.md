# Order wizard form state and validation, October 2, 2026

## Scope and result

This batch adopts `07-ui-ux-design.md#T-07.10.02.02` across simple electricity, advanced electricity, saving and solar together. With the preceding personal/company onboarding batch, all six customer wizards now use `FormStep`. Each keeps its partial field data in React Hook Form; Next validates the current stage, empty price/instruction stages skip field validation, and final Submit validates the full schema. Invalid final data returns to the relevant stage and focuses an enabled control. Localized feedback identifies the field and is linked with `aria-describedby`.

The shared `useWizardForm` retains typed strings, booleans and nested electricity quantities, composes functional updates, supports draft reset and revalidates edited touched/invalid fields. Existing catalogue, period, quantity, bill, address and consent rules feed live Zod schemas. The wrapper keeps controls and navigation disabled while validation or the existing save/submission command runs. Native buttons retain their keyboard behavior; no enclosing submit form changes auxiliary save, verification or address actions.

Existing draft versions and payloads, safe resumed stages, profile/geography membership, applied gift codes, renewable consent, financial review, authoritative solar review hashes, idempotency keys, departure protection and verified receipts remain in their established handlers. API/database code and transaction state are unchanged. Global adoption of the other form-system criteria remains open; this batch completes the four remaining customer wizard adoptions, not every form in the application.
